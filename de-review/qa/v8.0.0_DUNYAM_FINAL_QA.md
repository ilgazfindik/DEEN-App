## Cross-flow regression discovered and fixed
Final QA found a real integration defect: when the user was on the Shop tab, the room DOM could be absent, causing v7.8.9 `ODADA DENE` preview to fail even though isolated preview tests had passed.

v8.0.0 hardens `DEEN_WORLD_PREVIEW.open()`:
- if the room DOM is absent, temporarily renders the world room,
- opens the preview after the room is mounted,
- keeps Gold/owned/equipped unchanged during preview,
- restores the Shop tab after cancel/close.

Focused full-app validation after the fix at 390×844:

- tested item remained unowned during preview
- cancel closed preview
- Shop returned with 24 cards
- page errors: 0

## Known environment limitation
True browser reload/localStorage persistence over `file://` or localhost could not be certified in this environment because direct file/local HTTP navigation is blocked by administrator policy. Persistence logic was therefore not claimed as a full reload E2E PASS. Existing save/state code and remount-oriented guards remain in place.
