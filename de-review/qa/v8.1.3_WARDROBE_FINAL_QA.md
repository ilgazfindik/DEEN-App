## Important fix discovered during QA

The first v8.1.0 prototype was executing before the older World runtime finished creating `DEEN_WORLD`, so the new main-screen enhancer could miss the live World API. v8.1.3 now places the v8.1.x UI runtime after the complete v8.0.2 runtime chain. In addition, the area API is normalized because `DEEN_INTERACTIVE_WORLD.areas()` returns an object, not an array. The enhanced Dünyam shell now mounts successfully in browser smoke tests.
