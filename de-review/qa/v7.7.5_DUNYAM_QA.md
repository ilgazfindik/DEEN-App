# DEEN v7.7.5 — Dünyam Avatar Integrity & Runtime Stability QA

## Düzeltilen ana problemler

### 1. Karakter kaydedilince seçilen özelliklerin değişmesi / silinmesi
Kök neden birden fazla eski-yeni avatar katmanının aynı `state.myWorld.avatar` verisini farklı şemalarla normalize etmesiydi. Özellikle eski renderer yeni saç/sakal/kıyafet değerlerini tanımadığında default değerlere geri yazabiliyordu.

v7.7.5 ile:
- yeni avatar-library state'i canonical kabul edilir,
- eski `ensureAvatar()` yeni kayıtları artık mutate etmez,
- Dünyam, profil ve hareketli world character aynı canonical renderer'a bağlanır,
- save işleminde current draft doğrudan `state.myWorld.avatar` içine yazılır,
- aktif avatar slotları varsa aynı kayıtla senkronize edilir.

### 2. Karakteri tamamladıktan sonra oyunun takılması
Kök neden wizard'ın final save akışında hem eski global `updateUI()` hem de ilk-world handler'ın yeniden `DEEN_WORLD.render()` + `updateUI()` tetiklemesiydi. Bu, büyük tek-HTML uygulamada üst üste render zinciri oluşturabiliyordu.

v7.7.5 ile:
- final save tek transaction'a indirildi,
- karakter tamamlanınca mevcut dünya yalnızca görünür hale getiriliyor,
- dünya zaten varsa tekrar full render edilmiyor,
- world move artık 530 ms sonra tüm sahneyi yeniden render etmiyor,
- hızlı çift tıklamalar için 90 ms interaction guard eklendi,
- problemli ambient room hotspot noktaları kaldırıldı.
