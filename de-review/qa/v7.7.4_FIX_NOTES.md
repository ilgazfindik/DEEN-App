# DEEN v7.7.4 Fix Notes

## Fixed
1. **Avatar persistence bug**
   - Selected avatar features now save more reliably.
   - Current draft is normalized before save.
   - Active context slots are synced on save, so beard / outfit / glasses selections do not appear to disappear.
   - First-world avatar wizard now calls a direct draft commit method instead of relying only on the hidden save button.

2. **World freeze / broken click bug**
   - Ambient glowing room hotspots were disabled because they overlapped with furniture interactions and caused unstable behavior.
   - This removes the buggy invisible click targets the user marked in red.

3. **Legacy avatar compatibility cleanup**
   - Invalid old avatar values are normalized to valid current values.
   - Prevents older saved avatar schemas from breaking or partially resetting the current avatar.
