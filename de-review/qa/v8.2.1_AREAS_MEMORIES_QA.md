# DEEN v8.2.1 — Areas + Unit Memories / Collection QA

## Scope
- Premium Areas overlay for Study Corner, Reading Corner, and Garden.
- Locked/open/current-area states with Gold pricing and permanent unlock flow.
- Premium Unit Memories collection overlay for 15 unit keepsakes.
- Collection filters: All / Opened / Ready / Locked.
- Claimed keepsakes can be equipped in the room.
- Ready end-of-unit chests can be claimed from the collection UI through the existing reward API.
- Main Dünyam memory section gains a `Tümünü Gör` entry point; `•••` menu gains `Koleksiyon`.
- Existing Altın, area unlock, chest claim, and collectible equip state remain the source of truth.

## State / economy safety
- Area purchases continue through `DEEN_INTERACTIVE_WORLD.unlockNow()` and its existing ledger/Gold logic.
- Open-area switching continues through `DEEN_INTERACTIVE_WORLD.area()`.
- Keepsake rewards continue through `DEEN_WORLD.claimPathChest()`.
- Keepsake equip continues through `DEEN_WORLD.equipCollectible()`.
- No new secondary Gold, ownership, chest, or collectible state was introduced.
- NUR semantics and progression balance are unchanged.

## Known environment limitation
A true browser reload/localStorage persistence E2E test is not certified in this environment because normal localhost/file navigation is restricted. In-memory canonical state and the existing save APIs were exercised during smoke testing.
