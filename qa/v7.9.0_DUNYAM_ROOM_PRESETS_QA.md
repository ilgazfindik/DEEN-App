# DEEN v7.9.0 — Dünyam Room Presets QA

## Scope

This release adds three persistent room preset slots inside Oda Düzeni: Çalışma, Gece and Doğa. A preset stores the six canonical equipped decor fields (desk, rug, plant, shelf, window, nur) and reapplies them without touching currency, NUR, owned inventory or avatar fields.

## Runtime safety

- Presets reuse `state.myWorld.equipped`; they do not create a second active equip state.
- Stored preset data lives under `state.myWorld.roomPresets`.
- MutationObserver decoration is signature-gated to prevent self-triggered duplicate/re-render loops.
- Applying a preset closes an open room preview, clears transient action/idle state, refreshes existing decor renderers, then resumes idle behavior.
- Main Dünyam screen receives no new permanent control.

## Environment limitation

The full ~3.8 MB app was not claimed as a full monolithic browser regression. The environment blocks direct local navigation and historically times out on large `page.set_content` runs. QA therefore combines full-file JavaScript syntax validation with a focused Chromium integration harness using the real v7.9.0 runtime.
