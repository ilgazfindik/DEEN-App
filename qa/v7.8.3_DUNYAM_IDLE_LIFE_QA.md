# DEEN v7.8.3 — Idle Life & Ambient Behavior QA

## Scope
Adds non-blocking ambient idle behavior to Dünyam without changing canonical avatar data, rewards, room layout, or direct object interaction semantics.

## Added behaviors
- Continuous very subtle breathing while the avatar is idle.
- Short eye blink using the existing `g[data-layer="eyes"]` SVG layer.
- Random left/right glance micro-actions.
- Occasional NUR glance with a small ambient sparkle.
- Occasional window glance when the current room has a window.
- Idle behavior pauses while the avatar is moving, a v7.8.2 contextual action is active, edit mode is active, a bottom sheet is open, or Avatar Studio is open.
- User input immediately clears the current ambient action and resets the idle timer.
- Reduced-motion modes disable ambient animation.
