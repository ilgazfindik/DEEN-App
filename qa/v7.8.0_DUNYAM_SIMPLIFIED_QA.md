# DEEN v7.8.0 — Dünyam Simplified Navigation & Motion QA

## Scope
This release simplifies the Dünyam information architecture without replacing the existing avatar, room, reward, or object-interaction engines.

## Structural checks
- Legacy 5-button Dünyam tab bar remains in the DOM for compatibility but is visually hidden.
- Legacy 3-card area selector remains in the DOM for compatibility but is visually hidden.
- Legacy 4-button movement strip remains in the DOM for compatibility but is visually hidden.
- Main room now exposes one compact area selector, one Dünyam menu trigger, and two primary actions: **Hareket** and **Düzenle**.
- Dünyam menu exposes 6 destinations: Gardırop, Mağaza, Avatar, Koleksiyon, Alanlar, Oda Düzeni.
- Movement sheet exposes 4 actions.
- Area sheet exposes 3 areas and reuses the existing area/unlock engine.
- Wardrobe/shop subviews receive an **Odaya Dön** bar because the legacy top tabs are hidden.

## Motion polish
- Existing room movement engine remains authoritative.
- v7.8.0 only adds smoother visual walking interpolation, a short walking bob, pose pop, and arrival highlights for desk/window destinations.
- Canonical avatar state is not rewritten by this patch.
