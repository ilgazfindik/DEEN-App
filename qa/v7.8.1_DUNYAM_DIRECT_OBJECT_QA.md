# DEEN v7.8.1 — Dünyam Direct Object Movement QA

## Scope

This release makes the room itself the primary controller and removes the always-visible movement control from the main Dünyam screen.

## Implemented

- Main `HAREKET` action is removed from the room screen.
- `ODA DÜZENİ` remains as the single persistent room action.
- Room objects receive direct click / keyboard interaction bindings.
- Desk, rug, lamp, plant, shelf, NUR and collectible use the existing Living World interaction engine, so the character walks to the target and reacts.
- The window receives its own accessible direct tap target and moves the character to the window position.
- Manual `HAREKET` remains available as a fallback inside `Dünyam Menüsü`.
- First-use helper text explains `Eşyalara dokun`; it is marked seen after the first direct interaction.
- Tap pulse gives immediate visual feedback without changing avatar state.
- Existing v7.7.5–v7.8.0 avatar persistence, interaction watchdog and room asset systems are preserved.
