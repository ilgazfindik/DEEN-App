# DEEN v7.8.2 — Dünyam Contextual Character Actions QA

## Scope
v7.8.2 builds on v7.8.1 direct object movement. The purpose of this patch is to make object taps feel like short character actions rather than simple repositioning.

## Added contextual actions
- Desk: think/work animation + desk focus.
- Lamp: light-adjust animation.
- Rug: short seated/rest pose.
- Plant: bend/tend animation + leaf reaction.
- Shelf: reach/choose-book animation.
- NUR: short float/glow response.
- Collectible: inspect reaction.
- Window: longer look-outside animation.

## Stability behavior
- Only one contextual action can be active at a time.
- Starting another action cancels the previous action state and timers.
- Entering edit mode, switching areas/navigation, hiding the page, or pagehide clears active action state.
- After an action finishes, avatar SVG is restored using the canonical avatar state and current world pose.
- Reduced-motion users receive a shortened non-animated action state.
